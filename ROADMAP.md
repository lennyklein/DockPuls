# 🗺️ DockPuls Roadmap

Diese Roadmap zeigt die geplante Entwicklung von **DockPuls**.

DockPuls befindet sich aktuell im **Early Access**. Die Roadmap kann sich während der Entwicklung verändern. Funktionen können verschoben, erweitert oder durch neue Ideen ergänzt werden.

---

## ✅ Bereits verfügbar

Die folgenden Funktionen sind bereits Bestandteil von DockPuls:

* [x] 🐳 Container-Übersicht
* [x] 🟢 Running / Stopped Status
* [x] 📊 CPU-Auslastung der Container
* [x] 💾 RAM-Auslastung der Container
* [x] 🖥️ Host-Ressourcen
* [x] 🔄 Automatischer Live-Refresh
* [x] ⏱️ Refresh-Countdown
* [x] ▶️ Container starten
* [x] ⏹️ Container stoppen
* [x] 🔁 Container neustarten
* [x] 🐋 Docker-Deployment
* [x] 🌑 Dark-Mode-Dashboard
* [x] 📱 Responsive Grundstruktur

## 🎯 Langfristiges Ziel

Das langfristige Ziel von DockPuls ist eine **schlanke, moderne und erweiterbare Monitoring-Plattform für Homelabs**.

DockPuls soll dabei bewusst einfach bleiben und sich auf eine übersichtliche Benutzeroberfläche, wichtige Systeminformationen und eine einfache Verwaltung von Docker-Containern konzentrieren.

Durch das geplante Plugin-System soll die Plattform später flexibel erweitert werden können, ohne den Kern von DockPuls unnötig kompliziert zu machen.
